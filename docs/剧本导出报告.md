## 二、JP 解码约定（最终，已用位图验证）

**实机显示规则**：

```
显示字形 = MAP[code − 1]        (对所有码位成立，低位码没有例外)
```

验证锚点：`table[0x08B]=を`（位图确认）而文本用 code `0x08C` → 即 `index = code − 1`。

> ⚠️ 本报告下表用的 `export_script.jp_decode()` 在 `code < 0x20` 时取 `MAP[code]`（少减 1），
> 与编码器 `import_script.reverse_map()` 的 `index < 0x20 → code = index` 互为逆运算，
> 因此成品 ROM 显示正确，但**下表里的标点、数字比实机显示高一格**
> （实机 `4文字`，本表写作 `5文字`；实机 `「ええ、`，本表写作 `」ええ。`）。
> 详见 `docs/技术说明.md` 第二节、第十节第 2 条。

译文样例（JP 原版直读）：

```
データを記録しますか！
俺達が事務所に戻るなり
俺は苛立つ思いを抑えつつ，
俺達は佐藤亜希が住んでいた
俺達は淀橋署へとやって来た，
俺は書斎へと入って来た，
春菜「神宮寺さん。遅いですよ」
```
