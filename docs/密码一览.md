# 密码（パスワード）一览

《侦探神宫寺三郎 — 白影的少女》的「密码」是神宫寺系列的惯例彩蛋，**不是存档密码**。

## 机制

- 入口：标题画面主菜单第三项 `パスワード`（中文版菜单牌已重绘为「输入密码」）。
- 输入 **4 个英文字母**，输入正确就会播放与该密码对应的「おまけ」（附赠内容）。
- 游戏内的说明页（FAT 条目 432，由密码 `AAAA` 开启）原文：

  > 「パスワード」とは神宮寺シリーズの恒例であるおまけです。
  > タイトル画面の『パスワード』メニューから入力する事で、いろいろなおまけを見る事ができます。
  > **4 文字のアルファベット**の事です。
  > 正しいパスワードを入力すると、そのパスワードに対応した何かが始まります。
  > パスワードはいろんな所に隠されています。
  > それらのパスワードはパスワードと断って表示しているとも限りません。
  > **4 文字のアルファベットを見たらご注意下さい。**

- 输入界面文案在 FAT 条目 507：`文字を入力してください / Aボタンで入力 / Bボタンで取り消し / これで入力しますか！ / パスワードが合っていません`
- 可用字母：原版字库的拉丁字形只有 **A–P、R–Y**（共 24 个，**没有 Q 和 Z**），另有小写 `c`、`e`（只用于 `Ace` 一词）。所以密码不含 Q、Z。

## 不是密码的干扰项

- 条目 42 的酒吧问答里出现的 `NATO`、`APEC`、`OPEC` 是**问答题答案**（「北大西洋条約機構を略して何という」等），不是密码。
- `STAFF`、`NEXT`、`TROUBLE`、`GAME`、`BGM` 等是普通英文单词。
- 字库表、图形数据里出现的 `ABCDEF...` 长串是字形排列，不是密码。

## 对应奖励

- 输入正确后播放的是「おまけ」：**角色档案**（条目 418–431，14 页）、**神宫寺短篇故事**（433）、**工作人员留言**（434 / 435）、**音乐模式**（436）、**性格诊断测试**（437）、**STAFF**（466）等。
- 已知线索链：`AAAA` → 密码说明页（页尾给出 `SYKC`）；`SYKC` → STAFF 页（页首给出 `NSYS`）。
- 「哪个密码开哪一项」由可执行代码决定，文本里查不到；上面 17 个密码是全部。

## 排查时的一个坑（不影响成品）

`data/translation.tsv` 的 `jp_text` / `translation` 两列里，**码位小于 0x20 的标点和数字会比 ROM 实际显示“后一位”**。
例如条目 432 原文 ROM 显示的是 `4文字`，而表里写成 `5文字`；条目 433 的 `「今日2月6日……」` 在表里写成 `」今日3月7日……『`。

原因：`tools/export_script.py` 的 `jp_decode()` 对 `code < 0x20` 没有加 +1 偏移，而 `tools/import_script.py` 的 `reverse_map()` 用了同样的规则写回，引擎渲染时又是 `index = code - 1`——两个偏移正好抵消，所以**成品 ROM 显示是正确**的（已实测简中 ROM 条目 432 显示 `4`、条目 433 显示 `「今天2月6日是先生的生日！！」`）。

注意：正因为如此，改译文时不要把这个偏移“顺手修正”，否则反而会让 ROM 显示错位。
