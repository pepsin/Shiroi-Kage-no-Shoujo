# 工具输出目录

运行 `make outputs` 生成统一入口 **`work/index.html`**。自动游玩、录像和报告工具也会更新这个入口。
所有运行产物都在 `.gitignore` 排除的 `work/` 中，审核图不会提交到 Git。

| 内容 | 固定位置 |
| --- | --- |
| 推理题审核页 / 图片索引 | `work/autoplay/inference-review/index.html` / `index.json` |
| 推理题原始截图 | 同目录下 `00001-inference-e318.png` 等，按首次出现顺序编号 |
| 通关结果 / 进度 / 日志 | `work/autoplay/result.json` / `progress.json` / `run.log` |
| 通关末帧 | `work/autoplay/ending.png` |
| 分段存档、内存、截图和日志 | `work/autoplay/checkpoints/segment-0001.*` 起连续编号 |
| 新 ROM 重新验证 | `work/revalidate/checkpoints/`、`route.candidate.json`、`run.log` |
| 从探索记录导出的候选路线 | `work/route-export/route.candidate.json` |
| 录像 / 日志 | `work/video/playthrough.mp4` / `run.log` |
| 动态回归证据 | `work/dyn/`，按 `tests/dyn/checks.json` 的用例名组织 |
| 单段调试 | `work/dbg/play/play.ss1`、`play.ppm_final.ppm`、`run.log` |
| QA 报告 | `work/reports/qa-translation.tsv`、`style-lint.tsv`、`qa-style.json` |
| 上下文导出 | `work/reports/scene-context.tsv`、`qa-context.tsv` |
| 补丁校验与映射 | `work/reports/validated-patch.tsv`、`jp-map.tsv` |
| 漏翻扫描 | `work/reports/missing-runs.tsv`、`missing-structured.tsv`、`missing-gap-runs.tsv` |
| 控制字文本候选 | `work/reports/control-rows.tsv` |
| 调试渲染图 | `work/images/<工具名>.png`，如 `render-state.png`、`font-compare.png` |
| 字形表分页 | `work/glyph-sheets/sheet-0001.png` 起连续编号 |
| 翻译批次 | `work/tm/batches/b001.tsv` 起连续编号 |
| 剧本文本导出 | `work/dumps/script_text_jp/` 或 `script_text_cn/` |
| 本地测试日志 | `work/logs/unit.log`、`dynamic.log`、`verify.log` |
| ROM 备份 | `work/backup/侦探神宫寺三郎 - 白影的少女 (简中).gba` |

像素字体、精灵字形和单张截图预览分别为 `work/images/pixel-font.png`、
`sprite-glyphs.png`、`debug-shot.png`。

构建中间物继续使用 `work/font_patched.gba`、`work/glyph_map.ext.csv`，harness 为
`work/bin/gbarun_dbg`。可编辑的字形底稿固定为 `data/glyph_png/`，最终 ROM 固定为项目根目录的
`侦探神宫寺三郎 - 白影的少女 (简中).gba`。

## 运行与覆盖

```bash
make autoplay                                  # 从头重跑，更新 work/autoplay/
make autoplay AUTOPLAY_ARGS='--resume'          # 续跑同一目录，校验版本与断点
python3 tools/revalidate_autoplay.py            # 更新 work/revalidate/；不改已验收路线
make autoplay AUTOPLAY_ARGS='--route work/revalidate/route.candidate.json'
make video                                     # 更新 work/video/playthrough.mp4
python3 tools/export_scene_context.py --entries 316-416
```

自动游玩、重新验证、路线导出、录像、单段调试和字形表分页的输出目录由代码固定；
报告与图片工具也不接受输出路径参数。重复运行替换该工具自己的最新产物，不再生成日期或随机目录。
需要保留某次结果时，请在再次运行前自行复制。运行锁防止同一工具并发覆盖；若输入在即将清理的
输出目录内，会先报错，要求将输入移出。运行失败保留日志和断点，只有成功才生成通关结果。

报告与调试图片按固定文件名更新，不清理旁边的其他文件。
`work/scenes/`、`work/ds/` 中已有的翻译工作文件不会由输出目录整理过程修改。
旧运行和旧归档已清理；当前通关状态始终查看 `work/autoplay/result.json`。
