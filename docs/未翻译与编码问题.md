## 数字区间的内部编码

原版 e170 的四个选项实际是 **5、6年前／2、3年前／1、2年前／8年前**。
旧版中文版前三项显示成「六□七年前／三□四年前／二□三年前」；□代表空白槽。

引擎以 `glyph_index = code - 1` 取字形，工具对低于 `0x20` 的码位采用配套的内部表示。
主表 `6。7` 对应的原始码是 `0006 000C 0007`，实际画面是 `5、6`。
把它按字面翻成「六、七」，会同时改错数值，并把分隔符写成空白字形 `0x000B`。

| e170 引擎行／主表 idx | 解压绝对偏移 | 正确内部译文 | 实际显示 |
|---|---|---|---|
| 260 | `0x4C4E` | `6。7年前` | 5、6年前 |
| 264 | `0x4C9E` | `3。4年前` | 2、3年前 |
| 267 | `0x4CE2` | `2。3年前` | 1、2年前 |
| 270 | `0x4D26` | 保留 `9年前` | 8年前 |

多位数字也不能整体减一：`21。22才！` 实际显示 `10、11才？`。
保留编码器／解码器的配套约定，按原始码和真实字形修复已确认的行。
`tm.py` 已删除会掩盖错误分隔符的 `RANGE_DOT` 归一化，并增加回归测试。
单纯验证“ROM 解码结果等于主表”无法发现这类语义错误。

## 漏收的短标签

`extract_pool.scan_pools` 的长度下限为 2，后续池扫描也会过滤疑似噪声；
一字搜索标签和带内部数字 6 的 e505 选项因此没有进入主表。
本轮只补充经语境和唯一引用确认的槽，没有放开全局噪声过滤。

| 条目／引擎行 | 原文内部表示 | 新译内部表示 | 解压绝对偏移 | 原槽 |
|---|---|---|---|---|
| e299:2 | 絵 | 画 | `0xE6F` / 3695 | 4 字节 |
| e299:10 | 机 | 桌 | `0xEFF` / 3839 | 4 字节 |
| e505:51 | `6。7年くらい` | `6。7年左右` | `0x21CF` / 8655 | 16 字节 |

地下场景 7 个一字槽的语境、偏移和正常游玩证据见
[missing-search-labels.tsv](translation-audit/missing-search-labels.tsv)。
「台／声／柄」在相应场景中文语义成立，保留原字。

偏移约定：本页剧本池基址为解压偏移 `0x7A0`。普通 table 行 offset 是池内偏移；
pool 行 offset 是解压绝对偏移。引擎行号与主表 idx 不一定相同。
ROM 文件偏移加 `0x08000000` 才是 GBA ROM 地址，不能把解压偏移直接写入压缩文件。

## 地点栏与地图图片

场景顶栏来自 **e840 第二层 LZ77 位图**，并非 e417 字库文字。
e840 位于 file `0x472850`，有 418 组二级目录；地点条末尾是 32 字节头和
896 字节像素，即 112×16、4bpp、14×2 个图块。只搜索第一层解压数据会漏掉。
实际旧存档 `state-1357.ss1`、`state-1589.ss1` 的 VRAM 与公寓标签逐字节对应。

[tools/patch_location_labels.py](../tools/patch_location_labels.py) 使用
[data/location_labels.json](../data/location_labels.json) 中审定的固定像素，构建时无需系统字体。
资源最初用 STHeiti Medium 绘制：地点栏 9px，地图 11px，较窄标签降至 10px。
文字颜色、阴影和背景使用各资源原有调色索引。

补丁严格校验原像素或已翻译像素、完整非文字前缀、目录位置、邻接容量及 LZ77 往返。
所有地点条都放回原槽，主 FAT、e840 父地址和子资源指针不移动；重复应用结果不变。
普通压缩装不下时，使用考虑每 8 个 token 标志字节成本的固定槽压缩。
若仍超槽，或原资源已被未知修改，构建失败并停止。

地图 e712–e719 是独立的未压缩 OBJ 图块，每列先上 tile、后下 tile，不能照搬顶栏布局。
补丁只改 e712–e717 的像素范围，保留头、圆角、边框与透明区。
`verify_writes.py` 对地图只放行这些精确范围，地点补丁的 `--check` 进一步核对全部像素。

进入场景必须正常重载，不能用携带旧 VRAM 的旧即时存档截图证明新标签已生效。
本轮新 ROM 冷启动产生的正常场景画面已确认公寓地点栏、会客室、「桌／地／里」搜索标签、
e170 四个年份选项和 e505「5、6年左右」显示正确。
