## 2025 · 3月11日 / 3月12日 段「同义反复」清理

### 问题

`data/translation.tsv` 里 e1:2 / e1:3 把日文一句拆行时，把宾语和谓语都塞进第一行，
第二行只能拿同一个动词换说法补上：

```
JP  殺人事件など人の死を        ／ いろいろ見てきたが。
旧  凶杀和死人见过不少          ／ 见得多了。
```

「凶杀」与「死人」是同一件事的两种说法，加上「见过不少 / 见得多了」重复一次，
读起来是同义反复。

### 影响范围

不只这一处：把「**译文比日文多重复**」当成判据扫一遍（`work/dbg/redun.py`），
3/11（条目 1–15）与 3/12（条目 16–56）两段里共 **416 处**，去重 **206 组**。
其中日文本身就重复的（`ライター`／`アパート`／`記録する・しない`、`一方面…另一方面`
一类）属于忠实还原，保留；只由译文引入的重复逐条改写。

### 判据

对同一场景内相邻两行取最长公共汉字串：

* 译文相邻两行重复 `C`，日文对应两行重复 `J`；
* 当 `len(C) ≥ 2` 且 `len(C) − len(J) ≥ 1` 时判为「译文多出来的重复」。

按原版字节码的显示组合复核跨行整句，处理重复的谓语、推测语气和主语。
例如：

| 位置 | 旧译 | 新译 |
|---|---|---|
| 托儿所访谈 e503 | 人数其实并没有那么多／并没有那么多 | 人数其实／并不多 |
| 托儿所调查 e68 | 白跑一趟／说不定是白跑一趟 | 这回恐怕／白跑了一趟 |
| 公园搜索 e101 | 学生时代亜希的照片／学生时代的佐藤亜希 | 既然来了就找找看／孩子在不在这里 |
| 跟踪貴之 e116 | 跟着貴之／就跟着去吧 | 跟着貴之／走吧 |
| 人数推理 e178 | 神宮寺不是可疑男／不是可疑男 | 可这并不能证明神宮寺先生／不是可疑男子 |

表内省略引号等显示标记，斜线表示原有换行。公园搜索原文是在查找孩子，
旧译却误用了照片说明；本轮恢复了整句原意。

只有核对完整日文组合后，才同步修订其他条目的同义实例；不按单独的日文残句广播。
重写的整句涉及 861 个静态显示组合，另外检查被修改行的其他共用搭配。
共用句尾保留通用含义，例如 e207 的“小悠／亜希／流浪汉／大河原家”分支
统一接“应该不是吧”，避免所有选项都接成“小悠的事”。
