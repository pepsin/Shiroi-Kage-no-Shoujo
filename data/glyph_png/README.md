# 字形 PNG 导出（绘制/校对底稿）

每个字形一张 PNG，**用字本身命名**；中文版新做（追加）的字形在文件名末尾加 `（新）`。

* 尺寸：128×128（= 16×16 的 8 倍，最近邻放大，一个方块 = 一个像素）
* 颜色：游戏**原生文字调色板**，即玩家实际看到的样子
  * 背景 `(248,248,248)`
  * `(80,80,80)` = **字身**（像素值 1）
  * `(104,96,88)` = **右侧 1px 投影**（像素值 2）
* `manifest.tsv`：文件名 ↔ 字形下标/码位/是否新字/墨量 的对照表

## 原版字形的规格（实测自日文原版 ROM）

| 项 | 值 |
|---|---|
| 用色 | **只有 1、2 两级**（1703 个字形全部如此） |
| 字身 | **11×11 设计框**，位于单元格 `(0,1)`；中位尺寸 11×11，最大 12×12 |
| 投影 | **字身右侧 1px**（`值2`），自动生成；y 方向不投影 |
| 墨量 | 字身平均 **50.5 像素/字**；字身:投影 ≈ **65:35** |
| 单元格 | 16×16，右侧/下侧留白（所以字不会顶到边） |

> 早期版本用系统字体渲染成 1–15 全灰阶并填满 16×16，
> 结果实心笔画落在**接近白色**的调色板索引上（索引 15 ≈ 232），
> 于是又细又淡、大小也不对。现已按上表量化重做，与原版一致。

## 手工改字后怎么打回 ROM

改好 PNG（保持 128×128 或任意尺寸，会自动归一）后：

```bash
python3 tools/import_glyphs.py --rom out.gba --out out2.gba \
    --dir data/glyph_png --autoshadow
```

`--autoshadow` 会按原版规则由字身自动补出右侧投影；只想改新字可加 `--only-new`。
