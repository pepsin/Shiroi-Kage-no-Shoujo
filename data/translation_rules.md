# 翻译作业规范（译者/子代理必读）

本工程把 GBA《侦探神宫寺三郎 — 白影的少女》的日文剧本译成**简体中文**。
主翻译表：`data/translation.tsv`；译文按行回写游戏（每条字符串的槽位长度固定）。

## 一、硬性规则（违反即返工）

1. **标点原样保留**：字符种类、数量、先后顺序必须与原文完全一致。
   **原文没有标点的地方，译文也不要添加标点。**
   需要保留的标点：
   `、。，！？「」『』・：；“”‘’（）〈〉《》‥…□○■×＋＜＞％`
   - 例：`廊下には泣きはらした美しい女性と` 以 `と` 结尾，**没有标点**，译文也不得以标点结尾。
   - **`々` 要写成 `…`**（见下条）。
2. **`々` → `…`**：本作的 `々` 不是叠字符，而是**行尾的语塞/拖长记号**
   （全剧本 2035 处，多为 `早く々『`、`行くぞ々『`、`私は春菜々『`）。
   译文里一律写成单字符省略号 `…`（长度不变，占 1 个码位）：
   `」こっちだ。早く々『` → `」这边。快…『`。
   *例外*：姓氏 `佐々木` 里的 `々` 是真叠字符（原文写作 `佐ー木` 时 `ー` 才是叠字符），
   中文按**叠字写法**写成 `佐佐木`（不写 `佐々木`、也不写 `佐ー木`）。
3. `～`：
   - 作片假名长音符时（`デ～タ`=データ、`パスワ～ド`=パスワード、`キ～ホルダ～`）**不保留**，按词义翻译。
   - 作语气延长/波浪号时（`いや～`、`ぐわぁ～～`）**保留**。
4. 阿拉伯数字、拉丁字母：原样保留、顺序一致。
5. 译文**不得出现假名**（ぁ-ん、ァ-ヶ）。原文里以假名书写的人名，
   **恢复成汉字写法**（仍是同一个人名，不是意译）：
   `みその、ようこ` → `美園、洋子`、`ゆう` / `ゆうちゃん` → `悠` / `小悠`、
   `ささき、みえ` → `佐佐木、美恵`。完整对照见 `data/glossary.tsv` 末节。
6. **字数不得超过原文长度**（`len` 列 = 原文码数）；并尽量接近原文长度——游戏按原长排版，
   留白过多会显得空。可在不改变原意的前提下补足虚词、语气词。
7. 译文内不得含 TAB、换行。
8. **人名一律保留原文日文汉字写法，不做简体化**：
   `神宮寺三郎 / 洋子 / 春菜 / 貴之 / 知也 / 美鈴 / 佐藤亜希 / 大河原 / 北条隼人 / 熊野 /
   静江 / 礼子 / 哲司 / 哲三 / 智美 / 中西 / 拓朗 / 徳子 / 安田 / 新島 / 木下 / 荒川 / 前田`
   称呼 `さん / 君 / ちゃん / 様` 可省略或译作「先生 / 小姐 / 小～ / 大人」。
9. **除人名、地名等专有名词外，正文用简体中文**：
   `記録→记录、携帯電話→手机、調査→调查、時間→时间、証拠→证据、現場→现场`……
10. 地名/店名保留原样：`新宿 / 西新宿 / 歌舞伎町 / 淀橋署 / 中央公園 / アルタ / コマ劇場`。
11. **`ー`（长音符 U+30FC）在本作里是叠字符**：
     `佐ー木`=佐々木、`時ー`=時々、`人ー`=人々、`隅ー`=隅々、`散ー`=散々、`少ー`=少々。
     - 普通词汇里要**译掉**：`人ー`→`人们`、`時ー`→`有时`、`隅ー`→`每个角落`、`散ー`→`狼狈`。
     - **人名按中文叠字写**：`佐ー木` → `佐佐木`（长度不变，3 码位；不写 `佐ー木` 也不写 `佐々木`）。
12. **长度吃紧时的固定简称**（保持全篇一致）：
   `手帳` len=2 → `手册`（len≥3 时用 `记事本`）；`携帯電話` len=4 → `手机`。
13. **禁止倒装：不得照抄日语的语序**。游戏把一句话拆成若干显示行，日语的谓语在句末、
    修饰语在中心词前；逐行直译会让整句变成"宾语在前、动词在后"。行数、标点、每个槽位的
    长度都不能动，能动的只有**语序**——把动词提前，让修饰语跨行跟随。
    例（三行同一句，标点 `，` 只在末行）：
    ```
    原文  俺はふてくされた顔で / この会場から出て行く女性に / 目がとまった，
    错误  我带着不满的表情 / 向正走出会场的女性 / 目光停住了，
    正确  我板着脸 / 目光停在了正走出会场的 / 女性身上，
    ```
14. **行尾不要落在孤零零的动词上**。若一句的末行以光杆动词收尾（`…浮现出来，`、`…退去，`、
    `…被拍了下来，`），把它换成名词性落点或补一个小宾语（`…在脑海里浮现，`）。
    同理，`被 + 动词 + 了` 这类日式被动要改成主动（`照片上的人是学生时代的佐藤亜希，`
    胜过 `学生时代的佐藤亜希被拍了下来，`）。

## 二、风格：冷峻笔法

底子是 1993 年新宿的硬汉派私家侦探剧：主角神宮寺三郎第一人称叙述，**克制、简练、
不解释自己的情绪**。情绪由事实和动作带出，不由形容词带出。

- **能短则短**：一个动作一个短句，避免多层定语套叠；日语的连体修饰（`…という…`、
  `…ような…`）在中文里拆成短句或改用动词，不要写成"…的…的…"。
- **少用虚词与连接词**：能不写 `因为 / 所以 / 但是 / 而且 / 然后 / 非常 / 十分 / 相当`
  就不写，靠句子顺序表达因果与转折。
- **不堆语气词**：`呢 / 吧 / 啊 / 呀 / 哦` 只在说话人性格确实轻佻时用（真奈美、春菜等），
  叙述、刑警、委托人、静江一律不用。
- **不加戏**：不靠感叹号、夸张词、煽情描写制造效果；原文克制处译文要更克制。
- **对白口语化**：注意说话人身份（小学生、刑警、委托人、老人、女仆……），
  同一场景内人称、语气、称呼保持一致。
- 重复出现的系统提示（如 `デ～タを記録しますか！`）必须用**完全一致**的译法。
- 已定称呼：`神宮寺さん`→`神宮寺先生`、`洋子君`→`洋子`（君一律省略）、`礼子さん`→`礼子小姐`、
  `熊さん`→`熊先生`、`春菜さん`→`春菜小姐`、`お義母様`→`母亲大人`。

## 三、场景上下文（怎么拿到"同一段对话"）

游戏把一段对白存在**条目（entry）**里，但 `data/translation.tsv` 的行序是**存储顺序**：
- 条目 1 的正文按偏移分成三块（序幕正文 / 洋子问候与主人公独白 / 地点与系统串），
  顺序读文件会在三块之间反复跳；
- 后面的条目常在开头放系统块（存档询问、菜单），那不是剧情；
- 同一段文本会在多个条目里重复（e80/e126/e173/e215 是同一份 990 行）。

`tools/scene_index.py` 按**剧情推进**重建了顺序并切出场景：

| 命令 | 作用 |
|---|---|
| `python3 tools/scene_index.py build --report` | 重建 `data/scenes.tsv`（场景目录）与 `data/scene_lines.tsv`（每行 → 场景/位置/跨行标志） |
| `python3 tools/scene_index.py list --kind scene` | 看场景清单（id / 行数 / 地点 / 在场人物） |
| `python3 tools/scene_index.py show 3.0` | 把一个场景按剧情顺序逐行读出来（日文 + 现译） |
| `python3 tools/scene_index.py check` | 校验：101,795 行是否全部有场景归属 |

`scene_lines.tsv` 的 `join` 列标出一句话如何跨行：`>` 表示本行接下一行，`<` 表示承接上一行，
`<>` 表示中间行，`-` 表示本行收尾。**整句只在收尾的行有句读**，所以语序调整必须跨行做。

导出成批复核文件用 `tools/export_scene_context.py`：

```bash
python3 tools/export_scene_context.py --entries 1-20 --out work/scenes/e1_20.tsv   # 按条目
python3 tools/export_scene_context.py --flagged --limit 40 --out work/scenes/f1.tsv # 只挑疑似倒装/翻译腔
python3 tools/export_scene_context.py --scene 3.0                                   # 单场景直接看
```

作业时：**先通读整个场景**，确认说话人、地点、事件先后，再逐行改语序；
不要在不看整段的情况下单独改某一行。

**回写只改本场景的实例**（不按源文广播）：同一句日文在不同场景可能语气不同，
逐场景作业用 `tools/apply_cn_patch.py`（`entry<TAB>idx<TAB>新译文`）只改指定行；
`apply_cn_by_jp.py` 的广播只留给"确定全篇同义"的固定提示语。
代价是同一句可能出现多种译法，收尾时要专门归一（见 `docs/打包流程.md` 14.4）。

**逐批推进**：按场景顺序一批 10–20 个场景，每批走
`通读 → 改 → 校验 → 回写 → 复读`，改完 `scene_index.py show <场景>` 验收。

## 五、作业文件格式

批次输入文件是 TSV（表头固定）：

```
rid	entry	idx	len	jp_text
```

你只需产出**两列**的译文文件：

```
rid	cn
3:0	要记录数据吗！
3:1	保存记录
```

- 一行一条，`rid` 与输入完全对应，顺序、条数一致（不得漏行、不得多行）。
- 只写 `rid` 和译文，中间用 TAB 分隔；**不要**回抄 `jp_text`。
- `len` 是译文允许的最大字符数。
