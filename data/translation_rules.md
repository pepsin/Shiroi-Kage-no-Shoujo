# 翻译作业规范（译者/子代理必读）

本工程把 GBA《侦探神宫寺三郎 — 白影的少女》的日文剧本译成**简体中文**。
主翻译表：`data/translation.tsv`；译文按行回写游戏（每条字符串的槽位长度固定）。

## 一、硬性规则（违反即返工）

1. **标点原样保留**：字符种类、数量、先后顺序必须与原文完全一致。
   **原文没有标点的地方，译文也不要添加标点。**
   需要保留的标点：
   `、。，！？「」『』・：；“”‘’（）〈〉《》‥□○■×＋＜＞％々`
   - 例：`」こっちだ。早く々『` 的译文里必须按同样的相对位置出现 `」` `。` `々` `『`。
   - 例：`廊下には泣きはらした美しい女性と` 以 `と` 结尾，**没有标点**，译文也不得以标点结尾。
2. `～`：
   - 作片假名长音符时（`デ～タ`=データ、`パスワ～ド`=パスワード、`キ～ホルダ～`）**不保留**，按词义翻译。
   - 作语气延长/波浪号时（`いや～`、`ぐわぁ～～`）**保留**。
3. 阿拉伯数字、拉丁字母：原样保留、顺序一致。
4. 译文**不得出现假名**（ぁ-ん、ァ-ヶ）。原文里以假名书写的人名，
   **恢复成汉字写法**（仍是同一个人名，不是意译）：
   `みその、ようこ` → `美園、洋子`、`ゆう` / `ゆうちゃん` → `優` / `小優`、
   `ささき、みえ` → `佐々木、美恵`。完整对照见 `data/glossary.tsv` 末节。
5. **字数不得超过原文长度**（`len` 列 = 原文码数）；并尽量接近原文长度——游戏按原长排版，
   留白过多会显得空。可在不改变原意的前提下补足虚词、语气词。
6. 译文内不得含 TAB、换行。
7. **人名一律保留原文日文汉字写法，不做简体化**：
   `神宮寺三郎 / 洋子 / 春菜 / 貴之 / 知也 / 美鈴 / 佐藤亜希 / 大河原 / 北条隼人 / 熊野 /
   静江 / 礼子 / 哲司 / 哲三 / 智美 / 中西 / 拓朗 / 徳子 / 安田 / 新島 / 木下 / 荒川 / 前田`
   称呼 `さん / 君 / ちゃん / 様` 可省略或译作「先生 / 小姐 / 小～ / 大人」。
8. **除人名、地名等专有名词外，正文用简体中文**：
   `記録→记录、携帯電話→手机、調査→调查、時間→时间、証拠→证据、現場→现场`……
9. 地名/店名保留原样：`新宿 / 西新宿 / 歌舞伎町 / 淀橋署 / 中央公園 / アルタ / コマ劇場`。
10. **记号 `々` 与 `ー`（本作特例）**：
   - `々`：**一律保留**，位置不变（原文常用在句尾，如 `早く々『`）。
   - `ー`（长音符 U+30FC）：本作把它当作**叠字符**用：
     `佐ー木`=佐々木、`時ー`=時々、`人ー`=人々、`隅ー`=隅々、`散ー`=散々、`少ー`=少々。
     - 普通词汇里要**译掉**：`人ー`→`人们`、`時ー`→`有时`、`隅ー`→`每个角落`、`散ー`→`狼狈`。
     - **人名里保留原写法**：`佐ー木` 就写 `佐ー木`（人名不改）。
11. **长度吃紧时的固定简称**（保持全篇一致）：
   `手帳` len=2 → `手册`（len≥3 时用 `记事本`）；`携帯電話` len=4 → `手机`。

## 二、风格

- 1993 年新宿，硬汉派私家侦探剧；主角神宮寺三郎第一人称叙述，语气冷峻简练。
- 对白口语化，注意说话人身份（小学生、刑警、委托人、老人、女仆……）。
- 一个批次内的行是按剧本顺序排列的连续对白，请保持上下文连贯：人称、语气、称呼一致。
- 重复出现的系统提示（如 `デ～タを記録しますか！`）必须用**完全一致**的译法。
- 已定称呼：`神宮寺さん`→`神宮寺先生`、`洋子君`→`洋子君`、`礼子さん`→`礼子小姐`、
  `熊さん`→`熊先生`、`春菜さん`→`春菜小姐`、`お義母様`→`母亲大人`。

## 四、作业文件格式

批次输入文件是 TSV（表头固定）：

```
rid	entry	idx	len	jp_text
```

你只需产出**两列**的译文文件：

```
rid	cn
3:0	要记录数据吗！
3:1	保存记录
```

- 一行一条，`rid` 与输入完全对应，顺序、条数一致（不得漏行、不得多行）。
- 只写 `rid` 和译文，中间用 TAB 分隔；**不要**回抄 `jp_text`。
- `len` 是译文允许的最大字符数。
